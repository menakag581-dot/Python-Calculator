# Python Calculator

A simple calculator application developed using Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling

## Technologies Used

- Python

## How It Works

The program gets two numbers and an operator from the user.
It then performs the selected arithmetic operation and displays the result.

## Example

Enter first number: 20
Enter operator: *
Enter second number: 5

Result: 100.0
